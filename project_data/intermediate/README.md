
project_data/intermediate

Ce dossier contient les fichiers intermédiaires produits au cours du projet.

Il regroupe les fichiers générés à des étapes de travail intermédiaires, avant obtention d’un format final ou stabilisé.

Dans le cadre du projet, ce dossier peut contenir :

des fichiers de transition entre plusieurs étapes de traitement ;
des fichiers provisoires utiles au travail de l’équipe en parallèle ;
des fichiers préparatoires utilisés avant intégration complète dans la chaîne finale.

De nouveaux fichiers intermédiaires peuvent y être ajoutés au fil du POC 2 si les besoins du projet l’exigent.
